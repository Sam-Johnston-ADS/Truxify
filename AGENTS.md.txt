# Agent instructions for Truxify

- This is a large monorepo. Only touch the files explicitly named in the task.
- Match existing code style exactly — no new libraries, no reformatting unrelated code.
- Use the shared structured logger (`import logger from '../middleware/logger.js'`)
  instead of console.log/console.error, matching how it's used elsewhere in the same file.
- After any backend/api change, run `npm run lint && npm test` inside backend/api
  and confirm both pass before finishing the task.
- Keep diffs minimal: one root cause, one fix, per task.
- Do not modify package.json/lockfiles unless the task explicitly requires it.
